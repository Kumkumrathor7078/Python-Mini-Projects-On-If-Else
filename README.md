# Python Mini Projects on If-Else

A curated collection of practical Python mini projects built using only if-else statements. This repository is designed to strengthen conditional logic, decision-making, and problem-solving skills through hands-on programming practice.



## Overview

This repository contains a set of Python mini projects developed exclusively with **if-else statements**, without using loops or functions. Each project focuses on building a strong understanding of conditional programming and logical thinking through practical, real-world inspired scenarios.



## Projects Included
1.Smart Student Performance & Scholarship Analyzer 
2. Smart ATM Banking System
3. Employee Salary Management System
